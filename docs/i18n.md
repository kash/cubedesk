# Idiomas e internacionalización

CubeDesk admite actualmente inglés y español. El idioma se puede cambiar desde
**Ajustes → Idioma y región**.

## Cómo se guarda el idioma

La preferencia se guarda únicamente en la cookie:

```text
cubedesk_locale
```

No se guarda en la base de datos ni se vincula a la cuenta del usuario. La cookie dura un año, usa `SameSite=Lax` y se marca como `Secure` cuando la aplicación se sirve mediante HTTPS.

El orden para elegir el idioma es:

1. Un valor válido de `cubedesk_locale`.
2. El primer idioma indicado por `Accept-Language` del navegador.
3. Inglés como idioma predeterminado.

La lógica compartida está en [shared/i18n.ts](../shared/i18n.ts), y la integración SSR está en [server/router.tsx](../server/router.tsx).

## Estructura de traducciones

El proveedor y los hooks están en:

```text
client/i18n/index.tsx
```

El catálogo está organizado por dominios dentro de:

```text
client/i18n/messages/
├── index.ts
└── es/
    ├── admin.ts
    ├── auth.ts
    ├── common.ts
    ├── community.ts
    ├── legal.ts
    ├── navigation.ts
    ├── sessions.ts
    ├── settings.ts
    ├── solves.ts
    ├── stats.ts
    ├── timer.ts
    └── trainer.ts
```

No existe un catálogo inglés duplicado. Cuando el idioma es inglés, el sistema muestra la clave original como fallback. Esto evita mantener archivos vacíos que repitan exactamente los textos de la interfaz.

## Añadir o modificar una traducción

1. Usa como clave el texto original en inglés si el componente todavía utiliza
   ese formato:

   ```ts
   t('Delete session')
   ```

2. Añade la traducción española en el dominio correspondiente:

   ```ts
   'Delete session': 'Borrar sesión',
   ```

3. Para textos con datos variables, usa interpolación en vez de concatenar
   frases:

   ```ts
   t('Successfully deleted session "{name}"', {name: session.name})
   ```

   La traducción puede conservar una gramática natural:

   ```ts
   'Successfully deleted session "{name}"':
       'La sesión «{name}» se ha borrado correctamente.',
   ```

4. Si el texto pertenece a una opción, un placeholder, una etiqueta, un botón,
   un diálogo o un mensaje de error, pásalo igualmente por `t()` o utiliza uno de los componentes UI compartidos que ya lo hace automáticamente.

## Añadir otro idioma

Para añadir, por ejemplo, francés:

1. Añade `fr` a `SUPPORTED_LOCALES` en `shared/i18n.ts`.
2. Crea `client/i18n/messages/fr/` con los mismos dominios que `es/`.
3. Añade el catálogo `fr` a `client/i18n/messages/index.ts`.
4. Añade la opción `Français` al selector de idioma.
5. Mantén el fallback en inglés para las claves que todavía no estén traducidas.

La preferencia seguirá funcionando mediante cookie y no requerirá cambios de esquema ni migraciones de base de datos.

## Comprobaciones

Después de cambiar el sistema de idiomas, ejecuta:

```sh
CI=1 pnpm exec tsc --noEmit --pretty false
CI=1 pnpm run build
```

También conviene comprobar manualmente:

- cambiar de inglés a español desde Ajustes;
- recargar la página y comprobar que el idioma se conserva;
- abrir `/settings/timer` y otros diálogos;
- probar textos con nombres, contadores y mensajes de error dinámicos.
